# 凹版线稿工作台（Intaglio Linework Studio）

面向邮票雕刻凹版工艺的网页版线稿生成工具：从三维模型（glTF/GLB/OBJ）或照片直接生成可雕刻的连续矢量排线，支持方向场手刷、刀法分区、刀口约束校验、凹版印样预览与 SVG 出图。

## 技术栈

- TypeScript + Vite
- three.js（正交相机离屏渲染 G-buffer：法线、深度、亮度、遮罩）
- IndexedDB（选题档案、素材、线稿方案全部本地持久化）
- 零 UI 框架，原生 DOM + CSS 变量设计系统

## 安装与运行

```bash
pnpm install
pnpm dev        # 开发服务器，默认 http://127.0.0.1:5180
pnpm typecheck  # 严格类型检查
pnpm build      # 生产构建
```

## 六个页面

1. **选题档案**：套号/图序管理，票幅毫米尺寸与齿孔安全区锁定
2. **素材导入**：glTF/GLB/OBJ 模型、PNG/JPEG 照片上传，内置头像与古塔两个程序化测试模型
3. **线稿生成**：三维取景旋转、四通道场捕获、齿孔侵入自动拦截、流线追踪生成
4. **刀法调校**：方向场手刷（涂抹改向/擦除/撤销）、点刻/短线/长线分区、刀口与间距参数，停笔 220ms 防抖重算
5. **印样预览**：凹版油墨厚度浮雕、侧光调节、单色雕刻与胶印套印两种模式、多版并排、10 倍放大
6. **线稿出图**：1:1 与 5× 两档 SVG，每根线为宽度连续变化的闭合 ribbon 轮廓

## 引擎管线

```
三维模型 ──three.js G-buffer──┐
                              ├─ 法线梯度 → 结构张量 → 主曲率方向场
照片 ──亮度高度场伪法线───────┘                     │
                                                    ▼
                        手刷方向场融合 → 墨栅间距约束流线追踪
                                                    │
                  宽度随明暗连续变化 / 交叉层 / 点刻 / 轮廓描边
                                                    ▼
                  合规校验（EDT 墨隙）→ 印样浮雕预览 → 闭合轮廓 SVG
```

### 关键约束的实现方式

- **处处不小于最小间距**：`OccupancyGrid` 把每根已生成的线按真实刀口宽度栅格化，新线积分时逐点做净距硬检查
- **宽度连续无台阶**：线宽在每个积分点由暗度连续计算，落墨取相邻点均值，两端零宽收尖
- **无半截短线/毛刺**：被阻挡时补零宽收尖点；SVG 导出前做 ribbon 完整性自检
- **方向场 3 秒刷新**：手刷只改 96×96 低分角度网格，重算仅重跑流线追踪，防抖 220ms

  ui/          DOM 工具、画布组件、设计 token 消费层
  db/          IndexedDB 封装与序列化
  state/       会话状态、场缓存、方案存取
